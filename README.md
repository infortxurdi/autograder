## Descripción del proyecto

Repositorio de ejercicios prácticos de programación en **Java** acompañados de un sistema de **corrección automática (Autograder)** diseñado para trabajar en **Eclipse IDE**.

Cada bloque temático incluye:
- **Enunciados detallados** en la web (disponibles en **Euskara** y **Castellano**) con las firmas de los métodos, parámetros, casos límite y ejemplos.
- **Proyecto base descargable (`.zip`)** listo para importar directamente en Eclipse sin necesidad de configurar nada ni utilizar Git.
- **Evaluador automático (`Grader`)** que ejecuta pruebas sobre el código del alumnado y muestra en consola los resultados (`[OK]` / `[ERROREA]`) junto con la calificación obtenida.

### 🚀 Cómo empezar (Eclipse IDE)

1. Entra en la web de ejercicios: **[infortxurdi.github.io/autograder](https://infortxurdi.github.io/autograder/)**.
2. Selecciona el tema correspondiente y pulsa el icono de descarga para obtener el archivo **`.zip`**.
3. En Eclipse, importa el proyecto desde: `File` → `Import...` → `General` → `Existing Projects into Workspace` → `Select archive file`.
4. Implementa los métodos en `Ariketak.java` siguiendo las indicaciones de los comentarios Javadoc.
5. Configura `ConfigGrader.java` (`RUN_ALL` y `EXERCISE_NUMBER`) y ejecuta `Grader*.java` (`Run As` → `Java Application`) para comprobar tu nota.

**Java** programazioko ariketa praktikoen biltegia, **Eclipse IDE** ingurunean **zuzenketa automatikoa (Autograder)** egiteko prestatua.

- **Webgunea (Euskara / Castellano):** [https://infortxurdi.github.io/autograder/](https://infortxurdi.github.io/autograder/)
- **Deskarga zuzena:** Bloke bakoitzak bere `.zip` proiektua du Eclipse-n zuzenean inportatzeko (`Existing Projects into Workspace` → `Select archive file`).
- **Autoebaluazioa:** `Ariketak.java` osatu ondoren, exekutatu `Grader*.java` kontsolan emaitzak eta azken puntuazioa ikusteko.
