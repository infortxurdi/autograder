Arrayak: for indiziarekin eta while bukleak
Paketea: array
Klasea: Ariketak
📋 Jarraibideak
Osatu Ariketak.java fitxategiko metodo bakoitzaren logika, Javadoc iruzkinetan azaltzen diren zehaztapenak eta adibideak errespetatuz. Ariketa guztiak estatikoak dira (public static) eta adierazitako motako balioak itzuli behar dituzte.
DESKARGATU
A BLOKEA: FOR INDIZEAREKIN
Bloke honetako ariketak ebazteko indiziatutako for (int i = 0; i < array.length; i++) buklea erabili behar da.
1. Ariketa: batuElementuak
public static int batuElementuak(int[] zenbakiak)
Zenbaki osoen array bateko elementu guztien batura kalkulatzen du.
Parametroak int[] zenbakiak: aztertu nahi den int arraya.
Emaitza Elementu guztien batura osoa. 0 arraya nulua edo hutsik badago.
Adibideak
  • batuElementuak(new int[]{1, 2, 3, 4, 5}) → 15
  • batuElementuak(new int[]{-2, 5, -3}) → 0
  • batuElementuak(new int[]{}) → 0
  • batuElementuak(null) → 0

17. Ariketa: batuMugaraArte
public static int batuMugaraArte(int[] zenbakiak, int muga)
Zenbakiak batzen ditu lehen elementutik muga batera iritsi arte (muga gainditu gabe) while erabiliz.
Parametroak int[] zenbakiak: zenbaki osoen arraya.
int muga: baturak gainditu ezin duen gehienezko balioa.
Emaitza Lortutako gehienezko batura. 0 lehen elementua > muga bada edo arraya nulua badago.
Adibideak
  • batuMugaraArte(new int[]{10, 20, 15, 30}, 40) → 35 (10 + 20 <= 40; 10 + 20 + 15 > 40 denez geratu egiten da)
  • batuMugaraArte(new int[]{50, 10}, 40) → 0 (50 > 40 denez ezin du bat ere batu)
  • batuMugaraArte(null, 40) → 0

20. Ariketa: biAgerraldienArtekoDistantzia
public static int biAgerraldienArtekoDistantzia(int[] zenbakiak, int target)
Target balioaren lehenengo bi agerraldien arteko distantzia (indize kendura) kalkulatzen du while erabiliz.
Parametroak int[] zenbakiak: aztertu nahi den arraya.
int target: bilatu nahi den balioa.
Emaitza Bi agerraldien arteko distantzia (indize2 - indize1). -1 gutxienez bi aldiz agertzen ez bada.
Adibideak
  • biAgerraldienArtekoDistantzia(new int[]{4, 7, 2, 7, 9, 7}, 7) → 2 (3 - 1 = 2)
  • biAgerraldienArtekoDistantzia(new int[]{1, 5, 3}, 5) → -1 (behin bakarrik agertzen da)
  • biAgerraldienArtekoDistantzia(new int[]{3, 3}, 3) → 1 (1 - 0 = 1)
  • biAgerraldienArtekoDistantzia(null, 7) → -1
