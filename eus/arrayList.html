Java Programazio Ariketak
ArrayListak: Stringak, zenbakiak eta klase propioak
Paketea: arrayList
Klaseak: Ariketak, Ikaslea, Produktua
📋 Jarraibideak
Osatu Ariketak.java fitxategiko metodo bakoitzaren logika, Javadoc iruzkinetan azaltzen diren zehaztapenak eta adibideak errespetatuz. C blokeko ariketak ebatzi aurretik, Ikaslea.java eta Produktua.java klaseak sortu eta inplementatu beharko dituzu. Ariketak klaseko metodo guztiak estatikoak dira (public static).
DESKARGATU
A BLOKEA: STRING ZERRENDAK (ArrayList<String>)
Bloke honetako ariketak ebazteko ArrayList<String> klasearen metodoak (add, get, set, remove, contains, size...) erabili behar dira.
1. Ariketa: gehituErrepikatuGabe
public static boolean gehituErrepikatuGabe(ArrayList<String> zerrenda, String elementua)
Elementu bat zerrendaren amaieran gehitzen du, baldin eta aurretik zerrendan ez badago.
Parametroak ArrayList<String> zerrenda: testuen ArrayLista.
String elementua: gehitu nahi den testua.
Emaitza true elementua gehitu bada; false lehendik bazegoen edo parametroren bat nulua bada.
Adibideak
  • gehituErrepikatuGabe(["Ana", "Jon"], "Ane") → true (zerrenda: ["Ana", "Jon", "Ane"])
  • gehituErrepikatuGabe(["Ana", "Jon"], "Jon") → false (zerrenda: ["Ana", "Jon"])
  • gehituErrepikatuGabe(null, "Ane") → false
2. Ariketa: ezabatuLuzeraTxikikoak
public static int ezabatuLuzeraTxikikoak(ArrayList<String> hitzak, int gutxienekoLuzera)
Gutxieneko luzera baino karaktere gutxiago (< gutxienekoLuzera) dituzten hitz guztiak zerrendatik ezabatzen ditu (kontuz indizeekin elementuak ezabatzean).
Parametroak ArrayList<String> hitzak: aztertu eta aldatu beharreko String ArrayLista.
int gutxienekoLuzera: hitzak mantentzeko behar duen gutxieneko luzera.
Emaitza Ezabatutako hitzen kopurua. 0 zerrenda nulua bada.
Adibideak
  • ezabatuLuzeraTxikikoak(["Kaixo", "Ni", "Zu", "Euskara", "Ba"], 3) → 3 (zerrenda: ["Kaixo", "Euskara"])
  • ezabatuLuzeraTxikikoak(["Java", "Python"], 3) → 0
  • ezabatuLuzeraTxikikoak(null, 3) → 0
3. Ariketa: bilatuHitzLuzeena
public static String bilatuHitzLuzeena(ArrayList<String> hitzak)
Zerrendako hitzik luzeena aurkitzen du. Berdinketa badago, lehenengo agertzen dena bueltatzen du.
Parametroak ArrayList<String> hitzak: aztertu nahi den String ArrayLista.
Emaitza Hitzik luzeena. null zerrenda nulua edo hutsik badago.
Adibideak
  • bilatuHitzLuzeena(["katua", "txakurra", "arraina"]) → "txakurra"
  • bilatuHitzLuzeena(["bat", "hiru", "bost"]) → "hiru"
  • bilatuHitzLuzeena([]) → null
  • bilatuHitzLuzeena(null) → null

public static ArrayList<String> bihurtuMaiuskulara(ArrayList<String> hitzak)
Jatorrizko zerrendako hitz guztiak maiuskulara bihurtuta dituen ArrayList BERRI bat bueltatzen du. Jatorrizko zerrenda ez da aldatu behar.
Parametroak ArrayList<String> hitzak: jatorrizko String ArrayLista.
Emaitza Maiuskulaz dauden hitzen ArrayList berria. Zerrenda hutsa ([]) jatorrizkoa nulua bada.
Adibideak
  • bihurtuMaiuskulara(["kaixo", "Mundu"]) → ["KAIXO", "MUNDU"]
  • bihurtuMaiuskulara(null) → []
5. Ariketa: zenbatuHasieraLetra
public static int zenbatuHasieraLetra(ArrayList<String> hitzak, char letra)
Adierazitako letraz hasten diren zenbat hitz dauden zenbatzen du (maiuskulak eta minuskulak bereizi gabe).
Parametroak ArrayList<String> hitzak: String ArrayLista.
char letra: bilatu nahi den hasierako karakterea.
Emaitza Letra horrekin hasten diren hitzen kopurua. 0 zerrenda nulua edo hutsik badago.
Adibideak
  • zenbatuHasieraLetra(["Amaia", "ander", "Jon", "Aitor"], 'a') → 3
  • zenbatuHasieraLetra(["Jon", "Mikel"], 'a') → 0
  • zenbatuHasieraLetra(null, 'a') → 0
6. Ariketa: ordezkatuHitza
public static int ordezkatuHitza(ArrayList<String> hitzak, String zaharra, String berria)
Zerrendan agertzen diren zaharra hitz guztiak berria hitzarekin ordezkatzen ditu zerrendan bertan.
Parametroak ArrayList<String> hitzak: aldatu nahi den String ArrayLista.
String zaharra: ordezkatu nahi den hitza.
String berria: jarri nahi den hitz berria.
Emaitza Egindako ordezkapen kopurua. 0 parametroren bat nulua bada.
Adibideak
  • ordezkatuHitza(["gorria", "urdina", "gorria"], "gorria", "horia") → 2 (zerrenda: ["horia", "urdina", "horia"])
  • ordezkatuHitza(["urdina"], "gorria", "horia") → 0
  • ordezkatuHitza(null, "a", "b") → 0
7. Ariketa: bateratuErrepikatuGabe
public static ArrayList<String> bateratuErrepikatuGabe(ArrayList<String> z1, ArrayList<String> z2)
Bi zerrendetako elementu guztiak elkartzen ditu ArrayList BERRI batean, errepikapenik gabe eta agerpen-ordena mantenduz.
Parametroak ArrayList<String> z1: lehenengo String ArrayLista.
ArrayList<String> z2: bigarren String ArrayLista.
Emaitza Bi zerrenden batasuna duen ArrayList berria (errepikaturik gabe).
Adibideak
  • bateratuErrepikatuGabe(["A", "B", "A"], ["B", "C", "D"]) → ["A", "B", "C", "D"]
  • bateratuErrepikatuGabe(null, ["X", "X"]) → ["X"]
  • bateratuErrepikatuGabe(null, null) → []

9. Ariketa: ezabatuBalioGuztiak
public static boolean ezabatuBalioGuztiak(ArrayList<Integer> zenbakiak, int balioa)
Zerrendatik adierazitako zenbakiaren agerpen guztiak ezabatzen ditu (kontuz remove(int indizea) eta remove(Object balioa) bereiztean).
Parametroak ArrayList<Integer> zenbakiak: Integer ArrayLista.
int balioa: ezabatu nahi den zenbaki osoa.

  • ezabatuBalioGuztiak([1, 3, 5], 2) → false
  • ezabatuBalioGuztiak(null, 2) → false
10. Ariketa: batezBestekoaGainditzenDutenak
public static ArrayList<Double> batezBestekoaGainditzenDutenak(ArrayList<Double> notak)
Zerrendako noten batez besteko aritmetikoa kalkulatzen du, eta batez besteko hori baino hertsiki handiagoak (> batezBestekoa) diren notekin ArrayList BERRI bat bueltatzen du.
Parametroak ArrayList<Double> notak: Double motako noten ArrayLista.
Emaitza Batez bestekoa gainditzen duten noten ArrayList berria. Zerrenda hutsa ([]) nulua edo hutsik badago.
Adibideak
  • batezBestekoaGainditzenDutenak([4.0, 6.0, 8.0]) → [8.0] (batez bestekoa: 6.0)
  • batezBestekoaGainditzenDutenak([5.0, 5.0]) → []
  • batezBestekoaGainditzenDutenak(null) → []
11. Ariketa: txertatuOrdenatuta
public static void txertatuOrdenatuta(ArrayList<Integer> zerrendaOrdenatua, int berria)
Goranzko ordenan ordenatuta dagoen zerrenda batean zenbaki berri bat txertatzen du dagokion posizioan, zerrendak ordenatuta jarrai dezan.
Parametroak ArrayList<Integer> zerrendaOrdenatua: goranzko ordenan dagoen Integer ArrayLista.
int berria: txertatu nahi den zenbakia.
Emaitza void (zerrenda bera aldatzen du add(indizea, berria) erabiliz).
Adibideak
  • txertatuOrdenatuta([10, 20, 40, 50], 30) → zerrenda: [10, 20, 30, 40, 50]
  • txertatuOrdenatuta([10, 20], 5) → zerrenda: [5, 10, 20]
  • txertatuOrdenatuta([], 7) → zerrenda: [7]
12. Ariketa: bigarrenHandiena
public static int bigarrenHandiena(ArrayList<Integer> zenbakiak)
Zerrendako bigarren balio handiena (desberdina) aurkitzen du.
Parametroak ArrayList<Integer> zenbakiak: Integer ArrayLista.
Emaitza Bigarren zenbaki handiena. Integer.MIN_VALUE nulua bada edo 2 balio desberdin baino gutxiago baditu.
Adibideak

  • bigarrenHandiena([20, 20, 15, 10]) → 15
  • bigarrenHandiena([5, 5, 5]) → Integer.MIN_VALUE (-2147483648)
  • bigarrenHandiena(null) → Integer.MIN_VALUE (-2147483648)
13. Ariketa: aplikatuDeskontua
public static void aplikatuDeskontua(ArrayList<Double> prezioak, double ehunekoa)
Zerrendako prezio guztiei ehuneko deskontu bat aplikatzen die zerrendan bertan. Ehunekoa 0 baino txikiagoa edo 100 baino handiagoa bada, ez du aldaketarik egiten.
Parametroak ArrayList<Double> prezioak: Double motako prezioen ArrayLista.
double ehunekoa: deskontuaren ehunekoa (0.0 eta 100.0 artekoa).
Emaitza void (zerrendako elementuak eguneratzen ditu set() erabiliz).
Adibideak
  • aplikatuDeskontua([100.0, 50.0], 20.0) → zerrenda: [80.0, 40.0]
  • aplikatuDeskontua([100.0], -5.0) → zerrenda: [100.0]
14. Ariketa: iragaziTartea
public static ArrayList<Integer> iragaziTartea(ArrayList<Integer> zenbakiak, int min, int max)
[min, max] tartean dauden zenbakiekin (biak barne) ArrayList BERRI bat bueltatzen du.
Parametroak ArrayList<Integer> zenbakiak: jatorrizko Integer ArrayLista.
int min: gutxieneko balioa (barne).
int max: gehienezko balioa (barne).
Emaitza Tartean dauden zenbakien ArrayList berria. Zerrenda hutsa ([]) nulua bada.
Adibideak
  • iragaziTartea([5, 10, 15, 20, 25], 10, 20) → [10, 15, 20]
  • iragaziTartea(null, 10, 20) → []
C BLOKEA: KLASE PROPIOEN ZERRENDAK (Ikaslea eta Produktua)
Bloke honetako 15-20 ariketak egin aurretik, ikasleak ondorengo bi klaseak (Ikaslea eta Produktua) eraiki behar ditu arrayList paketearen barruan.
Klasea: Ikaslea.java
public class Ikaslea
Ikasle baten datuak gordetzen dituen klasea: izena, adina eta batez besteko nota.
Atributu pribatuak private String izena
private int adina
private double nota
Eraikitzailea public Ikaslea(String izena, int adina, double nota): atributu guztiak hasieratzen ditu.
Metodoak
  • public String getIzena() → ikaslearen izena bueltatzen du.
  • public int getAdina() → ikaslearen adina bueltatzen du.
  • public double getNota() → ikaslearen nota bueltatzen du.
  • public void setNota(double nota) → ikaslearen nota eguneratzen du.
  • public boolean gainditutaDago() → true bueltatzen du nota >= 5.0 bada; false bestela.
Klasea: Produktua.java
public class Produktua
Denda bateko produktu baten datuak gordetzen dituen klasea: izena, unitateko prezioa eta biltegiko stock kopurua.
Atributu pribatuak private String izena
private double prezioa
private int stock
Eraikitzailea public Produktua(String izena, double prezioa, int stock): atributu guztiak hasieratzen ditu.
Metodoak
  • public String getIzena() → produktuaren izena bueltatzen du.
  • public double getPrezioa() → produktuaren prezioa bueltatzen du.
  • public void setPrezioa(double prezioa) → produktuaren prezioa eguneratzen du.
  • public int getStock() → produktuaren stocka bueltatzen du.
  • public void setStock(int stock) → produktuaren stocka eguneratzen du.
  • public double guztizkoBalioa() → stock osoaren balio ekonomikoa kalkulatzen du (prezioa * stock).

public static ArrayList<String> lortuGaindituenIzenak(ArrayList<Ikaslea> ikasleak)

Parametroak ArrayList<Ikaslea> ikasleak: Ikaslea objektuen ArrayLista.

public static Ikaslea ikasleOnena(ArrayList<Ikaslea> ikasleak)
Notarik altuena duen Ikaslea objektua bueltatzen du. Berdinketa badago, lehenengo agertzen dena.

  • ikasleOnena(null) → null
17. Ariketa: igoNotaGuztiei
public static void igoNotaGuztiei(ArrayList<Ikaslea> ikasleak, double puntuak)
Zerrendako ikasle guztiei adierazitako puntuak gehitzen dizkie notan, baina 10.0 muga gainditu gabe. puntuak <= 0 badira edo zerrenda nulua bada, ez du ezer egiten.
Parametroak ArrayList<Ikaslea> ikasleak: Ikaslea objektuen ArrayLista.
double puntuak: gehitu nahi den puntu kopurua (> 0).
Emaitza void (ikasle bakoitzaren nota eguneratzen du setNota() erabiliz).
Adibideak
  • igoNotaGuztiei([Ikaslea("Ane",19,8.0), Ikaslea("Mikel",20,9.5)], 1.0) → Ane: 9.0, Mikel: 10.0
18. Ariketa: inbentarioarenBalioTotala
public static double inbentarioarenBalioTotala(ArrayList<Produktua> produktuak)
Biltegiko produktu guztien balio ekonomiko totala kalkulatzen du (produktu bakoitzaren prezioa * stock batura).
Parametroak ArrayList<Produktua> produktuak: Produktua objektuen ArrayLista.
Emaitza Inbentario osoaren balioa. 0.0 zerrenda nulua edo hutsik badago.
Adibideak
  • inbentarioarenBalioTotala([Produktua("Teklatua",25.0,4), Produktua("Sagua",15.0,2)]) → 130.0
  • inbentarioarenBalioTotala(null) → 0.0
19. Ariketa: erosiProduktua
public static boolean erosiProduktua(ArrayList<Produktua> produktuak, String izena, int kantitatea)
Izenaren arabera produktua bilatzen du (maiuskulak/minuskulak bereizi gabe). Produktua existitzen bada eta stock nahikoa badu (stock >= kantitatea eta kantitatea > 0), stocka murrizten du eta true bueltatzen du.
Parametroak ArrayList<Produktua> produktuak: Produktua objektuen ArrayLista.
String izena: erosi nahi den produktuaren izena.
int kantitatea: erosi nahi den unitate kopurua.
Emaitza true erosketa burutu bada; false produktua ez badago, stock nahikorik ez badago edo datuak okerrak badira.
Adibideak
  • erosiProduktua([Produktua("Teklatua",25.0,5)], "teklatua", 3) → true (stock berria: 2)
  • erosiProduktua([Produktua("Teklatua",25.0,2)], "teklatua", 4) → false (stocka 2 izaten jarraitzen du)
20. Ariketa: stockGutxikoProduktuak
public static ArrayList<Produktua> stockGutxikoProduktuak(ArrayList<Produktua> produktuak, int muga)
Adierazitako muga baino stock gutxiago (< muga) duten produktuekin ArrayList<Produktua> BERRI bat bueltatzen du.
Parametroak ArrayList<Produktua> produktuak: Produktua objektuen ArrayLista.
int muga: gutxieneko stock atalasea.
Emaitza Stock gutxiko produktuen ArrayList berria. Zerrenda hutsa ([]) zerrenda nulua bada.
Adibideak
  • stockGutxikoProduktuak([Produktua("A",10,2), Produktua("B",10,5), Produktua("C",10,1)], 5) → [A, C]
  • stockGutxikoProduktuak(null, 5) → []
