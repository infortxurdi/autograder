Java Programazio Ariketak
Kontrol Egiturak: baldintzak (if/else) eta hautaketa (switch/case)
Paketea: kontrolEgiturak
Klasea: Ariketak
📋 Jarraibideak
Osatu Ariketak.java fitxategiko metodo bakoitzaren logika, metodoen goiburuko Javadoc iruzkinetan azaltzen diren zehaztapenak errespetatuz. Ariketa guztiak estatikoak dira (public static) eta adierazitako motako balioak itzuli behar dituzte.
DESKARGATU
A BLOKEA: Baldintza-Egiturak (IF / ELSE)
Bloke honetako ariketak ebazteko if, else eta else if baldintza-egiturak erabili behar dira.
1. Ariketa: bikoitiaDaString
public static String bikoitiaDaString(int zenbakia)
Zenbaki bat bikoitia ala bakoitia den zehazten du testu bidez.
Parametroak SARRERAK int zenbakia: aztertu nahi den zenbaki osoa.
Emaitza Posibleak
  • "Bikoitia" — zenbakia bikoitia denean.
  • "Bakoitia" — zenbakia bakoitia denean.
2. Ariketa: bikoitiaDaBoolean
public static boolean bikoitiaDa(int zenbakia)
Zenbaki bat bikoitia den ala ez egiaztatzen du balio boolear bidez.
Parametroak int zenbakia: aztertu nahi den zenbaki osoa.
Emaitza Posibleak
  • true — zenbakia bikoitia bada.
  • false — zenbakia bakoitia bada.
3. Ariketa: zeinuZehaztu
public static String zeinuZehaztu(int zenbakia)
Zenbaki bat positiboa, negatiboa edo zero den zehazten du.
Parametroak int zenbakia: aztertu nahi den zenbaki osoa.
Emaitza Posibleak
  • "Positiboa" — zenbakia > 0 denean.
  • "Negatiboa" — zenbakia < 0 denean.
  • "Zero" — zenbakia == 0 denean.
4. Ariketa: notaSailkatu
public static String notaSailkatu(double nota)
Zenbakizko nota baten araberako kalifikazio-testua bueltatzen du.
Parametroak double nota: ikaslearen nota.
Emaitza Posibleak
  • "Bikaina" — nota >= 9.0 denean.
  • "Oso ongi" — nota >= 7.0 eta < 9.0 denean.
  • "Nahikoa" — nota >= 5.0 eta < 7.0 denean.
  • "Gutxi" — nota >= 0.0 eta < 5.0 denean.
  • "Nota ez-baliozkoa" — nota < 0.0 edo nota > 10.0 denean.
5. Ariketa: handienaZehaztu
public static int handienaZehaztu(int a, int b)
Bi zenbakiren artean handiena zein den bueltatzen du.
Parametroak int a: lehenengo zenbaki osoa.
int b: bigarren zenbaki osoa.
Emaitza Posibleak Bi zenbakietatik handiena dena (berdinak badira, edozein).
6. Ariketa: adinKategoriaSailkatu
public static String adinKategoriaSailkatu(int adina)
Adinaren arabera pertsona baten kategoria zehazten du.
Parametroak int adina: pertsonaren adina urteetan.
Emaitza Posibleak
  • "Adingabea" — adina < 18 denean.
  • "Heldua" — adina >= 18 eta < 65 denean.
  • "Adinekoa" — adina >= 65 denean.
  • "Adin ez-baliozkoa" — adina < 0 denean.
7. Ariketa: deskontuaKalkulatu
public static double deskontuaKalkulatu(double prezioa, boolean bazkideaDa, int adina)
Deskontua aplikatuz azken prezioa kalkulatzen du. Adingabekoek (%20) eta bazkide helduek (%10) deskontua dute.
Parametroak double prezioa: jatorrizko prezioa.
boolean bazkideaDa: pertsona bazkidea den edo ez.
int adina: pertsonaren adina urteetan.
Emaitza Posibleak Prezio berria deskontua aplikatu ondoren (double motakoa).
8. Ariketa: urteaBisestuaDa
public static boolean urteaBisestuaDa(int urtea)
Urte bat bisestua den ala ez egiaztatzen du. (Urte bat bisestua da 4rekin zatigarria bada eta ez 100ekin, edo 400ekin zatigarria bada).
Parametroak int urtea: aztertu nahi den urtea.
Emaitza Posibleak
  • true — urtea bisestua bada.
  • false — urtea ez bada bisestua.
B BLOKEA: Hautaketa-Egiturak (SWITCH / CASE)
Bloke honetako ariketak ebazteko switch / case egitura erabili behar da.
9. Ariketa: egunIzenaLortu
public static String egunIzenaLortu(int eguna)
Astearen egunaren zenbakia jasota (1etik 7ra), testuzko izena bueltatzen du.
Parametroak int eguna: egunaren zenbakia (1-7).
Emaitza Posibleak
  • 1: "Astelehena", 2: "Asteartea", 3: "Asteazkena", 4: "Osteguna", 5: "Ostirala", 6: "Larunbata", 7: "Igandea".
  • Gainerakoetarako: "Egun ez-baliozkoa".
10. Ariketa: asteburuaDa
public static String asteburuaDa(int eguna)
Egun zenbaki baten arabera laneguna ala asteburua den zehazten du.
Parametroak int eguna: egunaren zenbakia (1-7).
Emaitza Posibleak
  • "Laneguna" — 1etik 5era denean.
  • "Asteburua" — 6 edo 7 denean.
  • "Egun ez-baliozkoa" — gainerako zenbakietarako.
11. Ariketa: eragiketaEgin
public static int eragiketaEgin(int a, int b, char eragilea)
Bi zenbakiren arteko eragiketa matematikoa egiten du eragilearen arabera.
Parametroak int a: lehen zenbakia.
int b: bigarren zenbakia.
char eragilea: eragiketa ikurra ('+', '-', '*', '/').
Emaitza Posibleak Eragiketaren emaitza osoa (edo 0 zero bidez zatitzean edo eragilea okerra denean).
12. Ariketa: urtaroaLortu
public static String urtaroaLortu(int hilabetea)
Hilabetearen zenbakiaren arabera (1-12) dagokion urtaroa bueltatzen du (taldekatutako kasuekin).
Parametroak int hilabetea: hilabetearen zenbakia (1-12).
Emaitza Posibleak
  • "Negua" — 12, 1, 2 denean.
  • "Udaberria" — 3, 4, 5 denean.
  • "Uda" — 6, 7, 8 denean.
  • "Udazkena" — 9, 10, 11 denean.
  • "Hilabete ez-baliozkoa" — gainerako zenbakietarako.
13. Ariketa: hilabetekoEgunak
public static int hilabetekoEgunak(int hilabetea)
Hilabete baten egun kopurua bueltatzen du (urtea bisestua ez dela suposatuz).
Parametroak int hilabetea: hilabetearen zenbakia (1-12).
Emaitza Posibleak
  • 31 — 1, 3, 5, 7, 8, 10, 12 hilabeteetan.
  • 30 — 4, 6, 9, 11 hilabeteetan.
  • 28 — 2 hilabetean.
  • -1 — hilabetea 1-12 tartean ez badago.
