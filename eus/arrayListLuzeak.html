Auto Denda
Objektuei Bideratutako Programazioa: Auto-denda baten kudeaketa
Paketea: autodenda
Klaseak: Autoa, Saltzailea, Denda, Main
📋 Jarraibideak
Auto-denda bat kudeatzeko programa bat garatu behar duzu. Zuzenketa automatikoak (Autograder) behar bezala funtziona dezan, ezinbestekoa da klaseen, atributuen, eraikitzaileen eta metodoen izen zein parametro-motak beheko zehaztapenetan agertzen diren bezala errespetatzea. Azkenik, osatu Main.java klasea sistema osoa probatzeko.
DESKARGATU
1. BLOKEA: AUTOA KLASEA (Autoa.java)
Dendako autoen oinarrizko informazioa, deskontuak eta eskaintzen iraungitze-datak (java.util.Date) kudeatzen dituen klasea.
Klasearen egitura eta atributuak: Autoa
public class Autoa
Auto bakoitzak bere identifikazio-datuak, oinarrizko prezioa eta balizko eskaintza baten datuak (ehuneko deskontua eta iraungitze-data) gordetzen ditu.
Atributu pribatuak private String matrikula: autoaren matrikula.
private String modeloa: autoaren marka eta modeloa.
private double prezioa: eskaintzarik gabeko oinarrizko prezioa.
private int deskontua: deskontuaren ehunekoa (adib. 15 bada, %15). Hasieran 0.
private Date deskontuIraungitze: eskaintzaren amaiera-data (java.util.Date). Hasieran null.
Eraikitzailea public Autoa(String matrikula, String modeloa, double prezioa): jasotako parametroak esleitzen ditu eta eskaintza hasieratzen du (deskontua = 0, deskontuIraungitze = null).
Getter / Setter-ak Atributu guztien ohiko getter eta setter metodoak (getMatrikula, getModeloa, getPrezioa, getDeskontua, setDeskontua, getDeskontuIraungitze, setDeskontuIraungitze...).
1.1 Metodoa: getAzkenPrezioa
public double getAzkenPrezioa()
Autoaren benetako salmenta-prezioa kalkulatzen du, eskaintza bat aktibo dagoen kontuan hartuta. Eskaintza aplikatzeko, deskontua > 0 izan behar da eta deskontuIraungitze data egungo unea (new Date()) baino beranduagokoa izan behar da (ez dago iraungita).
Parametroak Ez du parametrorik jasotzen.
Emaitza Eskaintza indarrean badago, prezioa deskontua aplikatuta (prezioa * (1 - deskontua / 100.0)); bestela, oinarrizko prezioa.
Adibideak
  • prezioa = 20000.0, deskontua = 10 (indarrean) → 18000.0
  • prezioa = 20000.0, deskontua = 25 (iraungita) → 20000.0
  • prezioa = 15000.0, deskontua = 0 → 15000.0
2. BLOKEA: SALTZAILEA KLASEA (Saltzailea.java)
Dendako langileen salmentak, eskaintzen sorkuntza eta asteko lanaldiak kudeatzen dituen klasea.
Klasearen egitura eta atributuak: Saltzailea
public class Saltzailea
Saltzaile bakoitzak bere izena, saldu dituen autoen zerrenda eta asteko 7 egunetan kontratuz lan egin behar duen ordu-kopuruen zerrenda gordetzen ditu.
Atributu pribatuak private String izena: saltzailearen izena.
private List<Autoa> saldutakoAutoak: saltzaileak saldu dituen autoen zerrenda.
private List<Double> lanOrduak: asteko 7 egunetan (astelehenetik igandera) kontratuz lan egin behar dituen orduak adierazten dituen 7 elementuko zerrenda.
Eraikitzailea public Saltzailea(String izena, List<Double> lanOrduak): izena eta lan-orduak esleitzen ditu, eta saldutakoAutoak zerrenda hutsik (new ArrayList<>()) hasieratzen du.
2.1 Metodoa: salduAutoa
public void salduAutoa(Autoa autoa, Denda denda)
Auto baten salmenta burutzen du: autoa dendako stocketik (listaCoches) kentzen du eta saltzailearen saldutakoAutoak zerrendara gehitzen du.
Parametroak Autoa autoa: saldu nahi den autoa.
Denda denda: autoa dagoen denda.
Emaitza void (autoa dendako zerrendatik ezabatu eta saltzailearen zerrendan sartzen du).
2.2 Metodoa: sortuEskaintza (auto bakarra eta auto-zerrenda)
public void sortuEskaintza(Autoa autoa, int deskontua)
public void sortuEskaintza(List<Autoa> autoak, int deskontua)
Metodoaren gainkarga (overloading) erabiliz, auto bakar bati zein auto-zerrenda oso bati eskaintza ezartzen dio. Jasotako deskontua esleitzen du eta iraungitze-data egungo datatik hilabete batera (Calendar.MONTH + 1) ezartzen du.
Parametroak Autoa autoa edo List<Autoa> autoak: eskaintza jasoko duen autoa edo auto-zerrenda.
int deskontua: aplikatuko den deskontu-ehunekoa.
Emaitza void (autoaren edo autoen deskontua eta deskontuIraungitze eguneratzen ditu).
2.3 Metodoa: kalkulatuIrabaziak
public double kalkulatuIrabaziak()
Saltzaileak bere salmentekin lortu duen diru-kopuru totala kalkulatzen du, saldutako auto bakoitzaren azken prezioa (getAzkenPrezioa()) batuz.
Parametroak Ez du parametrorik jasotzen.
Emaitza Saldutako auto guztien azken prezioen batura (0.0 salmentarik egin ez badu).
3. BLOKEA: DENDA KLASEA (Denda.java)
Dendako auto-stocka, saltzaile-taldea, eskaintzen garbiketa eta irabazi orokorrak kudeatzen dituen klasea.
Klasearen egitura eta atributuak: Denda
public class Denda
Dendan saltzeko dauden autoen zerrenda eta bertan lan egiten duten saltzaileen zerrenda biltzen ditu.
Atributu pribatuak private List<Autoa> listaCoches: dendan saltzeko dauden autoen zerrenda (stocka).
private List<Saltzailea> listaVendedores: dendako saltzaileen zerrenda.
Eraikitzaileak public Denda(): bi zerrendak hutsik (new ArrayList<>()) hasieratzen ditu.
public Denda(List<Autoa> listaCoches, List<Saltzailea> listaVendedores): jasotako zerrendekin hasieratzen du denda.
3.1 Metodoa: garbituEskaintzak
public void garbituEskaintzak()
Dendako stockean (listaCoches) dauden auto guztiak aztertzen ditu, eta eskaintza iraungita dutenei (deskontuIraungitze.before(new Date())) deskontua (0) eta iraungitze-data (null) ezabatzen dizkie. Indarrean dauden eskaintzak ez dira ukitu behar.
Parametroak Ez du parametrorik jasotzen.
Emaitza void (iraungitako eskaintzak garbitzen ditu).
3.2 Metodoa: erakutsiIrabaziak
public void erakutsiIrabaziak()
Dendako saltzaile bakoitzaren izena eta lortutako irabaziak pantailatik inprimatzen ditu, eta amaieran saltzaile guztien irabazien batura totala erakusten du.
Parametroak Ez du parametrorik jasotzen.
Emaitza void (kontsolatik saltzaile bakoitzaren datuak eta guztirako totala erakusten ditu).
4. BLOKEA: PROGRAMA NAGUSIA (Main.java)
Programaren sarrera-puntua, sortutako klase eta metodo guztien funtzionamendu zuzena egiaztatzeko.
4.1 Proba-eszenatokia: Main
public static void main(String[] args)
Osatu Main metodoa urrats hauek jarraituz eta emaitzak kontsolatik bistaratuz:
1. Hasieraketa Sortu gutxienez 6 auto desberdin, 2 saltzaile (bakoitzari asteko 7 egunetako lanOrduak zerrenda esleituz) eta Denda objektu bat autoak eta saltzaileak gehituz.
2. Eskaintzak Sortu eskaintza bat auto bakarrarentzat eta beste bat auto-zerrenda batentzat. Horrez gain, simulatu auto batean iraungitako eskaintza bat (atzoko data jarriz) eta egiaztatu getAzkenPrezioa() metodoak ez duela deskontua aplikatzen.
3. Salmentak Burutu hainbat salmenta saltzaile ezberdinekin eta egiaztatu saldutako autoak dendako stocketik desagertu direla eta saltzaileen zerrendetan agertzen direla.
4. Irabaziak eta garbiketa Deitu erakutsiIrabaziak() metodora saltzaile bakoitzaren irabaziak eta totala ikusteko, eta exekutatu garbituEskaintzak() iraungitako eskaintza garbitu dela egiaztatzeko.
