Osatu poo.Ariketak klaseko metodoen logika Javadoc iruzkinekin bat etorriz. Ariketa hauetan klase laguntzaile hauek erabili beharko dituzu (dadaizkizun barne-klaseak):

DESKARGATU
  • Taxi: matrikula, udalerria, motoreMota (0=ezezaguna, 1=diesela, 2=gasolina) eta probintzia ("Bizkaia").
  • Kotxea: abiadura atributua kudeatzeko metodoak (bizkortu, geldotu).
  • Pertsona: izena, abizenak, adina eta getIzenOsoa().
  • Email eta Postontzia: posta elektronikoak kudeatzeko klaseak.
  • Ikasgela: pertsona/ikasle taldeak kudeatzeko klasea.
0. ARIKETA: ADIBIDE EBAZIA
Adibide honetan ikus dezakezu nola sortu objektu bat eta nola erabili bere metodoak.
0. Ariketa: taxiAdibidea (Ebatzita / Resuelto)
public static String taxiAdibidea(String matrikula, String udalerria)
Taxi objektu bat sortzen du, parametroak ezartzen dizkio setter bidez eta deskribapen testua bueltatzen du getter-ak erabiliz.
Parametroak String matrikula: autoaren matrikula.
String udalerria: taxiak lan egiten duen udalerria.
Emaitza "Taxi [Matrikula: {matrikula}, Udalerria: {udalerria}]"
A BLOKEA: Klase Oinarrizkoak eta Atributuak
Objektuak instanziatzea, atributuak ezartzea (setter/getter) eta bihurketak egitea.
1. Ariketa: taxiSortuEtaKonfiguratu
public static String taxiSortuEtaKonfiguratu(String matrikula, String udalerria, int motoreMota)
Taxi objektu bat sortu eta emandako datuekin konfiguratzen du.
Parametroak String matrikula: autoaren matrikula.
String udalerria: lan egiten duen udalerria.
int motoreMota: motor mota (0 = ezezaguna, 1 = diesela, 2 = gasolina).
Emaitza "Taxi [Matrikula: {matrikula}, Udalerria: {udalerria}, Motorra: {motoreMota}, Probintzia: Bizkaia]"
2. Ariketa: kotxeaBizkortuEtaGeldotu
public static int kotxeaBizkortuEtaGeldotu(int hasierakoAbiadura, int aldaketa)
Hasierako abiadura duen Kotxea sortu eta aldaketa aplikatzen dio (bizkortu aldaketa > 0 bada, edo geldotu aldaketa < 0 bada). Abiadura ezin da 0 baino txikiagoa izan.
Parametroak int hasierakoAbiadura: kotxearen abiadura hasieran.
int aldaketa: gehituko edo gutxituko den abiadura kopurua.
Emaitza Eguneratutako abiadura osoa (int).
3. Ariketa: celsiusToFahrenheit
public static double celsiusToFahrenheit(double celsius)
Celsius gradutan dagoen tenperatura Fahrenheit gradutara bihurtzen du.
Parametroak double celsius: tenperatura Celsius gradutan.
Formula & Emaitza Formula: (celsius * 9.0 / 5.0) + 32.0 → Fahrenheit tenperatura (double).
4. Ariketa: fahrenheitToCelsius
public static double fahrenheitToCelsius(double fahrenheit)
Fahrenheit gradutan dagoen tenperatura Celsius gradutara bihurtzen du.
Parametroak double fahrenheit: tenperatura Fahrenheit gradutan.
Formula & Emaitza Formula: (fahrenheit - 32.0) * 5.0 / 9.0 → Celsius tenperatura (double).
B BLOKEA: Pertsona Klasea (IMC eta Adina)
Objektuen arteko konparaketak eta kalkulu espezifikoak.
5. Ariketa: pertsonaZaharrena
public static String pertsonaZaharrena(Pertsona p1, Pertsona p2)
Bi pertsona jasotzen ditu eta zaharrena denaren izen-abizen osoa bueltatzen du. Berdinak badira, lehenengoa bueltatu.
Parametroak Pertsona p1: lehenengo Pertsona objektua.
Pertsona p2: bigarren Pertsona objektua.
Emaitza Pertsona zaharrenaren izen osoa ("Izena Abizenak").
6. Ariketa: kalkulatuIMC
public static int kalkulatuIMC(double pisua, double altuera)
Gorputz Masaren Indizea (GMI/IMC) kalkulatzen du: pisua (kg) / altuera^2 (m).
Parametroak double pisua: pertsonaren pisua kg-tan.
double altuera: pertsonaren altuera metrotan.
Emaitza Posibleak
  • -1 → IMC < 20.0 denean (pisu idealaren azpitik).
  • 0 → 20.0 <= IMC <= 25.0 denean (pisu idealean).
  • 1 → IMC > 25.0 denean (gehiegizko pisua).
7. Ariketa: adinezNagusikoaDa
public static boolean adinezNagusikoaDa(int adina)
Pertsona baten adina jasota, adin nagusikoa den ala ez zehazten du.
Parametroak int adina: pertsonaren adina urteetan.
Emaitza true adina >= 18 bada; false bestela.
