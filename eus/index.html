Java Programazio Ariketak: Grader Erabilera Gida
Autoevaluazio sistema automatikoa Eclipse IDE ingurunean
Ingurunea: Eclipse IDE / Java SE
Ebaluatzailea: Grader
💡 Zer da Grader sistema?
Grader sistema zure Java kodea modu automatikoan egiaztatzeko prestatutako lan-ingurunea da. Zure proiektuak hiru fitxategi nagusi ditu, bakoitza zeregin jakin batekin. Gida honetan fitxategi bakoitza nola erabili eta Eclipse-n probak nola exekutatu azalduko dizugu.
1. Proiektuaren Fitxategi Nagusiak
📄 1. Ariketak.java (Zure Kodea)

Hau da zure lan-eremua. Bertan inplementatu behar dituzu proposatutako ariketa guztien metodoak.

  • Metodo bakoitzaren gainean Javadoc iruzkin bat aurkituko duzu, parametroak, itzulitako balioak eta adibideak azalduz.
  • Zure kodea // TODO: Logika inplementatu... lerroaren ordez idatzi behar duzu.
  • Garrantzitsua: Ez aldatu metodoen izenak ezta parametroen motak ere, bestela Grader-ak ezingo ditu probatu.
⚙️ 2. GraderConfig.java (Konfigurazioa)

Fitxategi honen bidez zein ariketa probatu nahi duzun aukeratzen duzu.

public class GraderConfig { // true -> Ariketa GUZTIAK batera exekutatzen ditu // false -> EXERCISE_NUMBER egokitutako ariketa BAKARRA exekutatzen du public static final boolean RUN_ALL = false; // Probatu nahi duzun ariketaren zenbakia (1-13 tartean) public static final int EXERCISE_NUMBER = 1; }
  • Ariketa bakar bat lantzen ari zarenean, jarri RUN_ALL = false; eta aldatu EXERCISE_NUMBER dagokion zenbakira.
  • Guztiak amaitu dituzunean eta berrikuspen orokorra egin nahi duzunean, ezarri RUN_ALL = true;.
🚀 3. Grader[izenEspezifikoa].java (Ebaluatzaile Nagusia)

Fitxategi hau da Eclipse-n exekutatu behar duzun programa nagusia.

  • GraderConfig.java fitxategiko ezarpenak irakurtzen ditu eta zure kodea probatzen du automatikoki.
  • Ez duzu fitxategi honen barruko kodea aldatu behar; bakarrik exekutatu behar duzu.
2. Nola Erabili Eclipse-n (Urratsak)
  1. Idatzi kodea Ariketak.java fitxategian:
    Ireki Ariketak.java, aukeratu egin nahi duzun ariketa eta idatzi beharrezko Java kodea.
  2. Aukeratu ariketa GraderConfig.java fitxategian:
    Ireki GraderConfig.java eta adierazi landuko duzun ariketaren zenbakia (adibidez: EXERCISE_NUMBER = 1;).
  3. Exekutatu Grader-a Eclipse-n:
    Sakatu eskuineko botoiaz Grader[izenEspezifikoa].java fitxategian → Run As → Java Application.
  4. Aztertu emaitza Eclipse-ko Kontsolan (Console tab):
    Irteeran mezu hauek ikusiko dituzu:
    • [OK] : Zure kodeak test kasua egoki igaro du.
    • [ERROREA] : Emaitza ez da espero zena. Mezuan "Esperotakoa" eta "Lortutakoa" alderatuta agertuko zaizkizu zergatia ikusteko.
    • Azken puntuazioa: Exekuzioaren amaieran gainditutako proben portzentajea eta laburpena ikusiko dituzu.
