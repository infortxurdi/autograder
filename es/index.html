Ejercicios de Programación Java: Guía de Uso de Grader
Sistema de autoevaluación automático en el entorno Eclipse IDE
Entorno: Eclipse IDE / Java SE
Evaluador: Grader
💡 ¿Qué es el sistema Grader?
El sistema Grader es un entorno de trabajo preparado para verificar tu código Java de manera automática. Tu proyecto contiene tres archivos principales, cada uno con una tarea específica. En esta guía te explicamos cómo utilizar cada archivo y cómo ejecutar las pruebas en Eclipse.
1. Archivos Principales del Proyecto
📄 1. Ariketak.java (Tu Código)

Este es tu espacio de trabajo. En él debes implementar los métodos de todos los ejercicios propuestos.

  • Encima de cada método encontrarás un comentario Javadoc que explica los parámetros, valores devueltos y ejemplos.
  • Debes escribir tu código en lugar de la línea // TODO: Logika inplementatu....
  • Importante: No cambies los nombres de los métodos ni los tipos de parámetros; de lo contrario, Grader no podrá probarlos.
⚙️ 2. GraderConfig.java (Configuración)

A través de este archivo eliges qué ejercicio deseas probar.

public class GraderConfig { // true -> Ejecuta TODOS los ejercicios juntos // false -> Ejecuta UN SOLO ejercicio correspondiente a EXERCISE_NUMBER public static final boolean RUN_ALL = false; // Número del ejercicio que deseas probar (entre 1 y 13) public static final int EXERCISE_NUMBER = 1; }
  • Cuando estés trabajando en un solo ejercicio, pon RUN_ALL = false; y cambia EXERCISE_NUMBER al número correspondiente.
  • Cuando hayas terminado todos y quieras hacer una revisión general, establece RUN_ALL = true;.
🚀 3. Grader[nombreEspecifico].java (Evaluador Principal)

Este archivo es el programa principal que debes ejecutar en Eclipse.

  • Lee los ajustes del archivo GraderConfig.java y prueba tu código automáticamente.
  • No necesitas modificar el código de este archivo; solo debes ejecutarlo.
2. Cómo Usar en Eclipse (Pasos)
  1. Escribe el código en el archivo Ariketak.java:
    Abre Ariketak.java, elige el ejercicio que deseas hacer y escribe el código Java necesario.
  2. Selecciona el ejercicio en el archivo GraderConfig.java:
    Abre GraderConfig.java e indica el número del ejercicio en el que vas a trabajar (por ejemplo: EXERCISE_NUMBER = 1;).
  3. Ejecuta el Grader en Eclipse:
    Haz clic con el botón derecho en el archivo Grader[nombreEspecifico].java → Run As → Java Application.
  4. Analiza el resultado en la Consola de Eclipse (pestaña Console):
    En la salida verás estos mensajes:
    • [OK] : Tu código ha pasado el caso de prueba correctamente.
    • [ERROR] : El resultado no es el esperado. En el mensaje aparecerán comparados "Esperado" y "Obtenido" para identificar la causa.
    • Puntuación final: Al final de la ejecución verás el porcentaje de pruebas superadas y un resumen.
