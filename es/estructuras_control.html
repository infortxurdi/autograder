Ejercicios de Programación Java
Estructuras de Control: condiciones (if/else) y selección (switch/case)
Paquete: kontrolEgiturak
Clase: Ariketak
📋 Instrucciones
Completa la lógica de cada método en el archivo Ariketak.java, respetando las especificaciones descritas en los comentarios Javadoc de las cabeceras de los métodos. Todos los ejercicios son estáticos (public static) y deben devolver valores del tipo indicado.
DESKARGATU
BLOQUE A: Estructuras Condicionales (IF / ELSE)
Para resolver los ejercicios de este bloque se deben utilizar estructuras condicionales if, else y else if.
Ejercicio 1: bikoitiaDaString
public static String bikoitiaDaString(int zenbakia)
Determina si un número es par o impar mediante texto.
Parámetros ENTRADAS int zenbakia: el número entero que se desea analizar.
Resultados Posibles
  • "Bikoitia" — cuando el número es par.
  • "Bakoitia" — cuando el número es impar.
Ejercicio 2: bikoitiaDaBoolean
public static boolean bikoitiaDa(int zenbakia)
Comprueba si un número es par o no mediante un valor booleano.
Parámetros int zenbakia: el número entero que se desea analizar.
Resultados Posibles
  • true — si el número es par.
  • false — si el número es impar.
Ejercicio 3: zeinuZehaztu
public static String zeinuZehaztu(int zenbakia)
Determina si un número es positivo, negativo o cero.
Parámetros int zenbakia: el número entero que se desea analizar.
Resultados Posibles
  • "Positiboa" — cuando zenbakia > 0.
  • "Negatiboa" — cuando zenbakia < 0.
  • "Zero" — cuando zenbakia == 0.
Ejercicio 4: notaSailkatu
public static String notaSailkatu(double nota)
Devuelve el texto de calificación según una nota numérica.
Parámetros double nota: la nota del alumno.
Resultados Posibles
  • "Bikaina" — cuando nota >= 9.0.
  • "Oso ongi" — cuando nota >= 7.0 y < 9.0.
  • "Nahikoa" — cuando nota >= 5.0 y < 7.0.
  • "Gutxi" — cuando nota >= 0.0 y < 5.0.
  • "Nota ez-baliozkoa" — cuando nota < 0.0 o nota > 10.0.
Ejercicio 5: handienaZehaztu
public static int handienaZehaztu(int a, int b)
Devuelve cuál es el mayor entre dos números.
Parámetros int a: primer número entero.
int b: segundo número entero.
Resultados Posibles El mayor de los dos números (si son iguales, cualquiera).
Ejercicio 6: adinKategoriaSailkatu
public static String adinKategoriaSailkatu(int adina)
Determina la categoría de una persona según su edad.
Parámetros int adina: edad de la persona en años.
Resultados Posibles
  • "Adingabea" — cuando adina < 18.
  • "Heldua" — cuando adina >= 18 y < 65.
  • "Adinekoa" — cuando adina >= 65.
  • "Adin ez-baliozkoa" — cuando adina < 0.
Ejercicio 7: deskontuaKalkulatu
public static double deskontuaKalkulatu(double prezioa, boolean bazkideaDa, int adina)
Calcula el precio final aplicando un descuento. Los menores de edad (20%) y los socios adultos (10%) tienen descuento.
Parámetros double prezioa: precio original.
boolean bazkideaDa: indica si la persona es socia.
int adina: edad de la persona en años.
Resultados Posibles El nuevo precio tras aplicar el descuento (de tipo double).
Ejercicio 8: urteaBisestuaDa
public static boolean urteaBisestuaDa(int urtea)
Comprueba si un año es bisiesto o no. (Un año es bisiesto si es divisible por 4 y no por 100, o si es divisible por 400).
Parámetros int urtea: el año que se desea analizar.
Resultados Posibles
  • true — si el año es bisiesto.
  • false — si el año no es bisiesto.
BLOQUE B: Estructuras de Selección (SWITCH / CASE)
Para resolver los ejercicios de este bloque se debe utilizar la estructura switch / case.
Ejercicio 9: egunIzenaLortu
public static String egunIzenaLortu(int eguna)
Dado el número del día de la semana (del 1 al 7), devuelve su nombre en texto.
Parámetros int eguna: número del día (1-7).
Resultados Posibles
  • 1: "Astelehena", 2: "Asteartea", 3: "Asteazkena", 4: "Osteguna", 5: "Ostirala", 6: "Larunbata", 7: "Igandea".
  • Para el resto: "Egun ez-baliozkoa".
Ejercicio 10: asteburuaDa
public static String asteburuaDa(int eguna)
Determina si es un día laborable o fin de semana según el número del día.
Parámetros int eguna: número del día (1-7).
Resultados Posibles
  • "Laneguna" — cuando es del 1 al 5.
  • "Asteburua" — cuando es 6 o 7.
  • "Egun ez-baliozkoa" — para el resto de números.
Ejercicio 11: eragiketaEgin
public static int eragiketaEgin(int a, int b, char eragilea)
Realiza una operación matemática entre dos números según el operador.
Parámetros int a: primer número.
int b: segundo número.
char eragilea: símbolo de la operación ('+', '-', '*', '/').
Resultados Posibles El resultado entero de la operación (o 0 al dividir por cero o cuando el operador es incorrecto).
Ejercicio 12: urtaroaLortu
public static String urtaroaLortu(int hilabetea)
Devuelve la estación correspondiente según el número del mes (1-12) (utilizando casos agrupados).
Parámetros int hilabetea: número del mes (1-12).
Resultados Posibles
  • "Negua" — cuando es 12, 1, 2.
  • "Udaberria" — cuando es 3, 4, 5.
  • "Uda" — cuando es 6, 7, 8.
  • "Udazkena" — cuando es 9, 10, 11.
  • "Hilabete ez-baliozkoa" — para el resto de números.
Ejercicio 13: hilabetekoEgunak
public static int hilabetekoEgunak(int hilabetea)
Devuelve el número de días de un mes (asumiendo que el año no es bisiesto).
Parámetros int hilabetea: número del mes (1-12).
Resultados Posibles
  • 31 — en los meses 1, 3, 5, 7, 8, 10, 12.
  • 30 — en los meses 4, 6, 9, 11.
  • 28 — en el mes 2.
  • -1 — si el mes no está en el rango 1-12.
