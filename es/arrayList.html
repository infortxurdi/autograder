BLOQUE A: LISTAS DE STRING (ArrayList<String>)
Para resolver los ejercicios de este bloque se deben utilizar los métodos de la clase ArrayList<String> (add, get, set, remove, contains, size...).
1. Ejercicio: gehituErrepikatuGabe
public static boolean gehituErrepikatuGabe(ArrayList<String> zerrenda, String elementua)
Añade un elemento al final de la lista, siempre y cuando no exista previamente en ella.
Parámetros ArrayList<String> zerrenda: ArrayList de textos.
String elementua: texto que se desea añadir.
Resultado true si se ha añadido el elemento; false si ya existía o si alguno de los parámetros es nulo.
Ejemplos
  • gehituErrepikatuGabe(["Ana", "Jon"], "Ane") → true (lista: ["Ana", "Jon", "Ane"])
  • gehituErrepikatuGabe(["Ana", "Jon"], "Jon") → false (lista: ["Ana", "Jon"])
  • gehituErrepikatuGabe(null, "Ane") → false
2. Ejercicio: ezabatuLuzeraTxikikoak
public static int ezabatuLuzeraTxikikoak(ArrayList<String> hitzak, int gutxienekoLuzera)
Elimina de la lista todas las palabras que tengan menos caracteres que la longitud mínima indicada (< gutxienekoLuzera) (cuidado con los índices al eliminar elementos).
Parámetros ArrayList<String> hitzak: ArrayList de String que se debe analizar y modificar.
int gutxienekoLuzera: longitud mínima necesaria para mantener las palabras.
Resultado Número de palabras eliminadas. 0 si la lista es nula.
Ejemplos
  • ezabatuLuzeraTxikikoak(["Kaixo", "Ni", "Zu", "Euskara", "Ba"], 3) → 3 (lista: ["Kaixo", "Euskara"])
  • ezabatuLuzeraTxikikoak(["Java", "Python"], 3) → 0
  • ezabatuLuzeraTxikikoak(null, 3) → 0
3. Ejercicio: bilatuHitzLuzeena
public static String bilatuHitzLuzeena(ArrayList<String> hitzak)

Ejemplos

  • bilatuHitzLuzeena(["bat", "hiru", "bost"]) → "hiru"

6. Ejercicio: ordezkatuHitza
public static int ordezkatuHitza(ArrayList<String> hitzak, String zaharra, String berria)
Sustituye en la propia lista todas las apariciones de la palabra zaharra por la palabra berria.
Parámetros ArrayList<String> hitzak: ArrayList de String a modificar.
String zaharra: palabra que se desea sustituir.
String berria: nueva palabra que se desea colocar.
Resultado Número de sustituciones realizadas. 0 si algún parámetro es nulo.

7. Ejercicio: bateratuErrepikatuGabe
public static ArrayList<String> bateratuErrepikatuGabe(ArrayList<String> z1, ArrayList<String> z2)

Parámetros ArrayList<Double> prezioak: ArrayList de precios de tipo Double.

BLOQUE C: LISTAS DE CLASES PROPIAS (Ikaslea y Produktua)
Antes de realizar los ejercicios 15-20 de este bloque, el alumnado deberá construir las siguientes dos clases (Ikaslea y Produktua) dentro del paquete arrayList.
Clase: Ikaslea.java
public class Ikaslea
Clase que almacena los datos de un alumno o alumna: nombre, edad y nota media.
Atributos privados private String izena
private int adina
private double nota
Constructor public Ikaslea(String izena, int adina, double nota): inicializa todos los atributos.
Métodos
  • public String getIzena() → devuelve el nombre del alumno/a.
  • public int getAdina() → devuelve la edad del alumno/a.
  • public double getNota() → devuelve la nota del alumno/a.
  • public void setNota(double nota) → actualiza la nota del alumno/a.
  • public boolean gainditutaDago() → devuelve true si nota >= 5.0; false en caso contrario.
Clase: Produktua.java
public class Produktua
Clase que almacena los datos de un producto de una tienda: nombre, precio por unidad y cantidad de stock en almacén.
Atributos privados private String izena
private double prezioa
private int stock
Constructor public Produktua(String izena, double prezioa, int stock): inicializa todos los atributos.
Métodos
  • public String getIzena() → devuelve el nombre del producto.
  • public double getPrezioa() → devuelve el precio del producto.
  • public void setPrezioa(double prezioa) → actualiza el precio del producto.
  • public int getStock() → devuelve el stock del producto.
  • public void setStock(int stock) → actualiza el stock del producto.
  • public double guztizkoBalioa() → calcula el valor económico total del stock (prezioa * stock).

19. Ejercicio: erosiProduktua
public static boolean erosiProduktua(ArrayList<Produktua> produktuak, String izena, int kantitatea)
Busca un producto por su nombre (sin distinguir entre mayúsculas y minúsculas). Si el producto existe y tiene stock suficiente (stock >= kantitatea y kantitatea > 0), reduce su stock y devuelve true.
Parámetros ArrayList<Produktua> produktuak: ArrayList de objetos Produktua.
String izena: nombre del producto que se desea comprar.
int kantitatea: número de unidades que se desea comprar.
Resultado true si se ha realizado la compra; false si el producto no existe, no hay stock suficiente o los datos son incorrectos.
Ejemplos
  • erosiProduktua([Produktua("Teklatua",25.0,5)], "teklatua", 3) → true (nuevo stock: 2)
  • erosiProduktua([Produktua("Teklatua",25.0,2)], "teklatua", 4) → false (el stock sigue siendo 2)
