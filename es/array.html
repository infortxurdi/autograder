Ejercicios de Programación Java
Arrays: for indexado y bucles while
Paquete: array
Clase: Ariketak
📋 Instrucciones
Completa la lógica de cada método en el archivo Ariketak.java, respetando las especificaciones y ejemplos descritos en los comentarios Javadoc. Todos los ejercicios son estáticos (public static) y deben devolver valores del tipo indicado.
DESCARGAR
BLOQUE A: FOR INDEXADO
Para resolver los ejercicios de este bloque se debe utilizar un bucle indexado for (int i = 0; i < array.length; i++).
Ejercicio 1: batuElementuak
public static int batuElementuak(int[] zenbakiak)
Calcula la suma de todos los elementos de un array de números enteros.
Parámetros int[] zenbakiak: el array de int que se desea analizar.
Resultado La suma total de todos los elementos. 0 si el array es nulo o está vacío.
Ejemplos
  • batuElementuak(new int[]{1, 2, 3, 4, 5}) → 15
  • batuElementuak(new int[]{-2, 5, -3}) → 0
  • batuElementuak(new int[]{}) → 0
  • batuElementuak(null) → 0

Ejercicio 17: batuMugaraArte
public static int batuMugaraArte(int[] zenbakiak, int muga)
Suma números desde el primer elemento hasta alcanzar un límite (sin superarlo) utilizando while.
Parámetros int[] zenbakiak: array de números enteros.
int muga: valor máximo que la suma no puede superar.
Resultado La suma máxima obtenida. 0 si el primer elemento > muga o si el array es nulo.
Ejemplos
  • batuMugaraArte(new int[]{10, 20, 15, 30}, 40) → 35 (10 + 20 <= 40; al ser 10 + 20 + 15 > 40 se detiene)
  • batuMugaraArte(new int[]{50, 10}, 40) → 0 (como 50 > 40 no puede sumar ninguno)
  • batuMugaraArte(null, 40) → 0

Ejercicio 20: biAgerraldienArtekoDistantzia
public static int biAgerraldienArtekoDistantzia(int[] zenbakiak, int target)
Calcula la distancia (diferencia de índices) entre las dos primeras apariciones del valor target utilizando while.
Parámetros int[] zenbakiak: el array que se desea analizar.
int target: el valor que se desea buscar.
Resultado La distancia entre las dos apariciones (índice2 - índice1). -1 si no aparece al menos dos veces.
Ejemplos
  • biAgerraldienArtekoDistantzia(new int[]{4, 7, 2, 7, 9, 7}, 7) → 2 (3 - 1 = 2)
  • biAgerraldienArtekoDistantzia(new int[]{1, 5, 3}, 5) → -1 (solo aparece una vez)
  • biAgerraldienArtekoDistantzia(new int[]{3, 3}, 3) → 1 (1 - 0 = 1)
  • biAgerraldienArtekoDistantzia(null, 7) → -1
